Alphabet:

a. Upper (A-Z) and lower case letters (a-z) of the English alphabet
	- from "A" ... "Z" and from "a" ... "z"
b. Decimal digits (0-9);
c. Underline character '_';

Lexic:
	1. Special symbols, representing:
- operators +, -, *, /, =, <, <=, =, >=, %, ==
- separators [ ] { } ; space
- reserved words:
•	array  
•	char  
•	const 
•	else  
•	if 
•	int  
•	of 
•	read 
•	string 
•	while
•	print

	2. identifiers
  - sequence of letters (upper and lower case) and  digits, such that the first character is a letter; the rule is:
    identifier = letter{letter | digit}
    letter = "a" | "b" | ... | "z" | "A" | ... | "Z" 
    digit = "0" | "1" |...| "9"
      
	3. constants

constant = noconst | conststring |  character

1.integer - rule:
      noconst = "+" no | "-" no | no
      no = nonzerodigit{digit}
      nonzerodigit = “1” | “2” | ... | “9”

2.character
      char = 'letter' | 'digit'

3.string
      conststring = "string"
      string = char{char}
